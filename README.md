# abuzahra — أبو زهرة لشراء الأثاث المستعمل بالرياض

صفحة هبوط ثابتة (ملف HTML واحد بدون أدوات بناء) منشورة على GitHub Pages بالنطاق `https://abuzahra.abads.site` — بنفس طريقة صفحة `kitch`.

- `index.html` — الصفحة كاملة: Meta + Open Graph + Canonical + Schema (LocalBusiness + FAQPage) + نموذج تسعير واتساب + تتبع gtag/dataLayer.
- `og-image.jpg` — صورة المشاركة في واتساب والشبكات (1200×630).
- `favicon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — الأيقونات.
- `CNAME`, `robots.txt`, `sitemap.xml`, `404.html`.

**النشر:** GitHub Pages ينشر من الفرع `gh-pages` (نسخة مطابقة من `main`). أي تعديل يُرفع على الفرعين.

**DNS:** سجل `CNAME` باسم `abuzahra` في نطاق abads.site (Hostinger) يشير إلى `abuomerrahama-lab.github.io`.

بيانات التواصل في متغيرات أعلى السكربت داخل `index.html`: `BRAND_NAME`, `PHONE_NUMBER` (0551141527), `WHATSAPP_NUMBER` (966551141527).

لتفعيل تتبع إعلانات جوجل: ضع معرف `AW-XXXXXXXXX` وتسميات التحويل في `GADS_ID` و `CONVERSION_LABELS`.

**الصور:** مجلد `img/` (WebP بمقاسين 480 و 800) — صور مجانية من Pexels (رخصة Pexels تسمح بالاستخدام التجاري بدون نسب): 7464266، 6758770، 6312357، 38788452، 17158638، 6283970، 5483233. يُفضّل استبدالها لاحقاً بصور حقيقية لسيارات وفريق أبو زهرة.
